Initial public release of Sparse Sort.

- Reorder selected Obsidian folders and save automatically when you drop an item.
- Keep untouched folders on native sorting, without recording every vault file.
- Use touch handles, desktop multi-selection, pins, hiding rules, and per-folder reset.
- Import selected Flexplorer folder orders with configuration backups.

Requires Obsidian 1.13.0 or newer. Download `main.js`, `manifest.json`, and `styles.css`, or extract the ZIP into your vault's `.obsidian/plugins/sparse-sort/` folder. Enable Sparse Sort in Community plugins.

Desktop and Chromium touch emulation have been checked. iOS hardware behavior is not yet verified. Concurrent sorting changes from multiple devices are not merged.
