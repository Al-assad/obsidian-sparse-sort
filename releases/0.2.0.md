First public release of Sparse Sort.

- Save manual order only for rearranged folders; untouched folders keep native sorting.
- Insert files and folders at an exact position in another folder, including child-to-parent moves.
- Drag left at a subtree boundary to select an ancestor insertion level.
- Check a destination path and indentation-aligned insertion line before releasing.
- Hold over a folder center for 600 ms to arm moving into it; Undo is available after a move.
- Keep pins, hidden items, selected Flexplorer imports, and automatic persistence.
- Block conflicting names and self/descendant moves; failed moves attempt rollback.

Requires Obsidian 1.13.0 or newer. Install `main.js`, `manifest.json`, and `styles.css` in `.obsidian/plugins/sparse-sort/`, or extract the ZIP into that folder.

The build passes 28 automated tests plus live Obsidian desktop and Chromium touch-emulation checks for cross-folder insertion and undo. iOS hardware behavior remains unverified. Concurrent device edits are not merged.
